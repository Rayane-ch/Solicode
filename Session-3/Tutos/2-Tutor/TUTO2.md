#Administrator Actions


1. Dashboard:

- Navigate to Articles management.

- Navigate to Categories management.

- Logout.


2. Article Management:

- View the list of articles **(Read)**.

- Add a new article **(Create)**.

- Edit an existing article **(Update)**.

- Delete an article **(Delete)**.


3. Category Management:

- View the list of categories **(Read)**.

- Add a new category **(Create)**.

- Edit an existing category **(Update)**.

- Delete a category **(Delete)**.
